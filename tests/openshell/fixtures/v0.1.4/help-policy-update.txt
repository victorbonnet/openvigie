Incrementally update policy on a live sandbox

USAGE
  openshell policy update [OPTIONS] [NAME]

FLAGS:
      --add-endpoint <ADD_ENDPOINTS>
          Add or merge an endpoint: host:port[:access[:protocol[:enforcement[:options]]]]. Options include allowed-ip=..., credential rewrite flags, and allow-uninspected-credentials

      --remove-endpoint <REMOVE_ENDPOINTS>
          Remove an endpoint: host:port

      --add-allow <ADD_ALLOW>
          Append an allow rule: `host:port[,port...]:METHOD:path_glob`. List every port on the target endpoint. Requires --rule-name and the complete --binary list or --any-binary

      --add-deny <ADD_DENY>
          Append a deny rule: `host:port[,port...]:METHOD:path_glob`. List every port on the target endpoint. Requires --rule-name and the complete --binary list or --any-binary

      --remove-rule <REMOVE_RULES>
          Remove a network rule by name

      --binary <BINARIES>
          Add a binary to --add-endpoint, or declare every binary of an L7 target rule

      --rule-name <RULE_NAME>
          Name the target rule for L7 appends, or override one --add-endpoint rule name

      --any-binary
          Explicitly declare that the target rule for L7 appends allows any binary

      --endpoint-path <ENDPOINT_PATH>
          Select an exact endpoint path for L7 appends; an empty value selects no path. This is distinct from the appended method/path matcher

      --dry-run
          Preview the merged policy without sending it to the gateway

      --wait
          Wait for the sandbox to load the policy revision

      --timeout <TIMEOUT>
          Timeout for --wait in seconds
          
          [default: 60]

  [NAME]
          Sandbox name (defaults to last-used sandbox)

GATEWAY FLAGS:
  -g, --gateway <GATEWAY>
          Gateway name to operate on (resolved from stored metadata)
          
          [env: OPENSHELL_GATEWAY=]

      --gateway-endpoint <GATEWAY_ENDPOINT>
          Gateway endpoint URL (e.g. <https://gateway.example.com>). Connects directly without looking up gateway metadata
          
          [env: OPENSHELL_GATEWAY_ENDPOINT=]

      --gateway-insecure
          Skip TLS certificate verification for gateway connections
          
          [env: OPENSHELL_GATEWAY_INSECURE=]

GLOBAL FLAGS:
      --workspace <WORKSPACE>
          Workspace scope for resource operations
          
          [env: OPENSHELL_WORKSPACE=]
          [default: default]

  -v, --verbose...
          Increase verbosity (-v, -vv, -vvv)

      --color <WHEN>
          When to colorize output. `auto` colorizes only when stdout is a terminal

          Possible values:
          - auto:   Colorize a stream only when that stream is a terminal and no environment override applies
          - always: Always colorize, even when output is redirected
          - never:  Never colorize
          
          [env: OPENSHELL_COLOR=]
          [default: auto]

  -h, --help
          Print help

  -V, --version
          Print version
